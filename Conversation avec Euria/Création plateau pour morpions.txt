🎯 Objectif : Créer un plateau de morpion (3x3 cases) dans App.vue
Tu es sur VSCode, avec ton projet Vue déjà lancé, et tu vas travailler dans le fichier src/App.vue.

🧱 1. Comprendre ce qu’est un fichier .vue
Un fichier .vue, c’est comme une boîte magique qui contient 3 parties :

<template> → C’est la partie “visuelle” : ce que tu vois à l’écran (les cases du morpion).
<script> → C’est la partie “cervelle” : ce qui fait fonctionner le jeu (qui joue, qui gagne…).
<style> → C’est la partie “décoration” : les couleurs, les formes, les tailles.
Tu vas écrire du code dans ces 3 parties, mais on commence par le <template> : le plateau.

🎨 2. Créer le plateau (3x3 cases) dans le <template>
Imagine que tu dessines 3 lignes, et dans chaque ligne, tu mets 3 cases.

Tu vas écrire ça :

vue
Copier
<template>
  <div class="plateau">
    <div class="ligne">
      <div class="case">?</div>
      <div class="case">?</div>
      <div class="case">?</div>
    </div>
    <div class="ligne">
      <div class="case">?</div>
      <div class="case">?</div>
      <div class="case">?</div>
    </div>
    <div class="ligne">
      <div class="case">?</div>
      <div class="case">?</div>
      <div class="case">?</div>
    </div>
  </div>
</template>
👉 Explication simple :

<div class="plateau"> → c’est la grande boîte qui contient tout le jeu.
<div class="ligne"> → chaque ligne de 3 cases.
<div class="case">?</div> → chaque case, avec un ? pour l’instant (on remplacera par des ronds ou croix plus tard).
🎨 3. Donner un style aux cases (dans <style>)
Tu veux un fond coloré ? On va faire un fond bleu clair, avec des cases blanches, et des bordures.

Ajoute ça en bas du fichier, dans la partie <style> :

vue
Copier
<style>
.plateau {
  display: flex;
  flex-direction: column;
  gap: 5px;
  background-color: #e0f7fa;
  padding: 20px;
  border-radius: 10px;
}

.ligne {
  display: flex;
  gap: 5px;
}

.case {
  width: 100px;
  height: 100px;
  background-color: white;
  border: 2px solid #333;
  display: flex;
  align-items: center;
  justify-content: center;
  font-size: 40px;
  font-weight: bold;
  cursor: pointer;
}
</style>
👉 Explication simple :

.plateau → la boîte principale, avec un fond bleu clair.
.ligne → chaque rangée de 3 cases, alignées horizontalement.
.case → chaque case : 100x100 pixels, blanche, avec un bord noir, et un gros texte au milieu (le ?).
cursor: pointer → quand tu passes la souris, elle devient une main → ça veut dire “tu peux cliquer ici”.

🎯 Objectif : Créer un plateau de morpion 3x3
On veut 3 lignes, et dans chaque ligne, 3 cases → ça fait 9 cases au total.

🧱 1. Le fichier App.vue = une boîte magique en 3 parties
Dans Vue, un fichier .vue est comme une boîte à 3 tiroirs :

php
Copier
📁 App.vue
├── 📄 <template> → ce que tu vois à l’écran (les cases)
├── 📄 <script> → ce qui fait fonctionner le jeu (qui joue, qui gagne…)
└── 📄 <style> → comment c’est décoré (couleurs, tailles, formes)
Pour l’instant, on ne touche que le <template> et le <style>. Le <script> viendra plus tard.

🧩 2. Dans le <template> : on construit le plateau avec des “div”
💡 Qu’est-ce qu’un <div> ?
C’est comme une boîte vide que tu peux mettre n’importe où. Tu peux lui donner un nom (une “classe”), une taille, une couleur, etc.

Exemple :

html
Copier
<div class="case">?</div>
→ C’est une boîte appelée “case”, avec un ? à l’intérieur.

🧱 3. Comment on fait les lignes et les colonnes ?
On va utiliser deux niveaux de boîtes :

🔹 Niveau 1 : La grande boîte → le plateau
html
Copier
<div class="plateau">
  <!-- ici, on va mettre les 3 lignes -->
</div>
🔹 Niveau 2 : Chaque ligne → une boîte avec 3 cases
html
Copier
<div class="ligne">
  <div class="case">?</div>
  <div class="case">?</div>
  <div class="case">?</div>
</div>
→ On fait ça 3 fois (pour 3 lignes).

🧭 4. Comment les cases s’alignent-elles en colonnes ?
C’est grâce à CSS (la partie <style>). On va expliquer ça juste après, mais d’abord, voyons le code complet du <template> :

vue
Copier
<template>
  <div class="plateau">
    <!-- Ligne 1 -->
    <div class="ligne">
      <div class="case">?</div>
      <div class="case">?</div>
      <div class="case">?</div>
    </div>
    <!-- Ligne 2 -->
    <div class="ligne">
      <div class="case">?</div>
      <div class="case">?</div>
      <div class="case">?</div>
    </div>
    <!-- Ligne 3 -->
    <div class="ligne">
      <div class="case">?</div>
      <div class="case">?</div>
      <div class="case">?</div>
    </div>
  </div>
</template>
👉 Pourquoi ça marche ?

Parce que chaque <div class="ligne"> contient 3 <div class="case">, et qu’on va dire à l’ordinateur :

“Dans chaque ligne, mets les cases côte à côte (horizontalement)”.
Et les lignes, mets-les les unes en dessous des autres (verticalement).”

🎨 5. Dans le <style> : on dit comment les boîtes doivent s’organiser
Voici le code, avec des explications très simples :

vue
Copier
<style>
.plateau {
  display: flex;
  flex-direction: column;
  gap: 5px;
  background-color: #e0f7fa;
  padding: 20px;
  border-radius: 10px;
}
</style>
🔍 Explication ligne par ligne :
display: flex; → “Dis à cette boîte qu’elle va organiser ses enfants (les lignes) d’une certaine façon.”
flex-direction: column; → “Mets les enfants (les lignes) les unes en dessous des autres.” → ça fait les 3 lignes verticales.
gap: 5px; → “Laisse 5 pixels d’espace entre chaque ligne.”
background-color: #e0f7fa; → “Mets un fond bleu clair.”
padding: 20px; → “Laisse 20 pixels d’espace autour du plateau (pour que ce soit joli).”
border-radius: 10px; → “Arrondis les coins.”
🔹 Maintenant, les lignes :
css
Copier
.ligne {
  display: flex;
  gap: 5px;
}
display: flex; → “Dis à cette boîte (la ligne) qu’elle va organiser ses enfants (les cases) d’une certaine façon.”
gap: 5px; → “Laisse 5 pixels d’espace entre chaque case.”
👉 Par défaut, flex met les enfants côte à côte → donc les 3 cases sont alignées horizontalement → ça fait une ligne !

🔹 Et les cases :
css
Copier
.case {
  width: 100px;
  height: 100px;
  background-color: white;
  border: 2px solid #333;
  display: flex;
  align-items: center;
  justify-content: center;
  font-size: 40px;
  font-weight: bold;
  cursor: pointer;
}
width: 100px; height: 100px; → “Fais en sorte que chaque case fasse 100x100 pixels.”
background-color: white; → “Fond blanc.”
border: 2px solid #333; → “Bordure noire de 2 pixels.”
display: flex; → “Dis à la case qu’elle va centrer son contenu (le ?).”
align-items: center; justify-content: center; → “Mets le ? au milieu, à la fois horizontalement et verticalement.”
font-size: 40px; → “Gros texte.”
cursor: pointer; → “Quand la souris passe, elle devient une main → ça veut dire ‘tu peux cliquer ici’.”
🧩 Résumé visuel (comme un schéma)
css
Copier
[PLATEAU] → contient 3 [LIGNE] → chaque [LIGNE] contient 3 [CASE]
   │
   ├── [LIGNE 1] → [CASE] [CASE] [CASE]
   ├── [LIGNE 2] → [CASE] [CASE] [CASE]
   └── [LIGNE 3] → [CASE] [CASE] [CASE]
→ Grâce à display: flex, les lignes sont verticales, et les cases dans chaque ligne sont horizontales.
