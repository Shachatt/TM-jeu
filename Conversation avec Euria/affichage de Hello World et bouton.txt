Merci pour ton retour, Shaïna — c’est super que tu aies vu le compteur affiché à 0 ! 🎉
Mais si le clic ne fait rien, c’est souvent parce que Vue ne sait pas que le compteur peut changer — il faut lui dire : “Attention, ce nombre peut bouger !”

🛠️ Problème : counter n’est pas réactif
Dans Vue 3, quand tu veux que quelque chose change à l’écran quand tu modifie une variable, tu dois utiliser ref().

→ let counter = 0 → ça ne marche pas pour les clics.
→ const counter = ref(0) → ça marche !

✅ Solution : Remplace let counter = 0 par const counter = ref(0)
1. Dans App.vue, va dans la partie <script setup>
Tu as peut-être ça :

vue
Copier
<script setup>
let counter = 0
</script>
→ Remplace-le par :

vue
Copier
<script setup>
import { ref } from 'vue'

const counter = ref(0)
</script>
✅ import { ref } from 'vue' = on dit à Vue : “Je veux utiliser ref pour créer une variable qui peut changer.”
✅ const counter = ref(0) = on crée une variable réactive qui commence à 0.

2. Sauvegarde avec Ctrl + S (ou Cmd + S)
→ Ton site se rafraîchit tout seul !
→ Clique sur le bouton → le compteur augmente ! 🎉

🧠 Pourquoi ça marche maintenant ?
Avant : let counter = 0 → c’était une variable normale → Vue ne savait pas qu’elle pouvait changer.
Maintenant : ref(0) → c’est une variable réactive → Vue surveille les changements → et met à jour l’écran.
