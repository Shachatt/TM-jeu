🧱 Étape 4 : Comment on écrit le <script> ?
On va créer :

1. Un état (data) → ce qui change dans le jeu
js
Copier
data() {
  return {
    joueurActuel: 'O', // au début, c’est le joueur 1 (rond)
    plateau: [
      '', '', '',  // ligne 1
      '', '', '',  // ligne 2
      '', '', ''   // ligne 3
    ]
  }
}
→ joueurActuel : qui joue maintenant. → plateau : ce qu’il y a dans chaque case.

2. Une fonction (methods) → ce qu’on fait quand on clique
js
Copier
methods: {
  jouer(index) {
    // 1. Vérifier si la case est vide
    if (this.plateau[index] === '') {
      // 2. Mettre le symbole du joueur actuel dans la case
      this.plateau[index] = this.joueurActuel;
      // 3. Changer de joueur
      this.joueurActuel = this.joueurActuel === 'O' ? 'X' : 'O';
    }
  }
}
→ jouer(index) : la fonction qui est appelée quand on clique sur une case. → index : le numéro de la case (0 à 8).

🧩 Étape 5 : Comment on lie le <template> au <script> ?
Dans le <template>, on va :

Afficher le contenu de chaque case → {{ plateau[index] }}
Appeler la fonction jouer(index) quand on clique → @click="jouer(index)"
Mais comment on donne le bon index à chaque case ?

→ On va utiliser une boucle (comme un “pour chaque case, fais ça”).

🔄 Étape 6 : Pourquoi on utilise une boucle et pas 9 fois le même code ?
Parce que si on écrit 9 fois :

html
Copier
<div class="case" @click="jouer(0)">...</div>
<div class="case" @click="jouer(1)">...</div>
...
→ C’est possible, mais c’est long, répétitif, et facile à se tromper.

→ En programmation, on aime éviter la répétition → on utilise une boucle.

🧭 Étape 7 : Comment on fait une boucle dans Vue ?
On utilise v-for → “pour chaque élément dans un tableau, affiche ça”.

Exemple :

vue
Copier
<div v-for="(case, index) in plateau" :key="index" class="case" @click="jouer(index)">
  {{ case }}
</div>
→ v-for="(case, index) in plateau" → pour chaque case dans le tableau plateau, on a accès à la case elle-même (case) et à son numéro (index). → :key="index" → c’est important pour que Vue sache quelle case est quelle. → @click="jouer(index)" → quand on clique, on appelle la fonction jouer avec le bon numéro. → {{ case }} → affiche ce qu’il y a dans la case (vide, ‘O’, ou ‘X’).

🧱 Étape 8 : Comment on organise les cases en 3 lignes ?
On va faire 3 boucles, une pour chaque ligne.

→ On va découper le tableau plateau en 3 parties :

js
Copier
computed: {
  ligne1() {
    return this.plateau.slice(0, 3);
  },
  ligne2() {
    return this.plateau.slice(3, 6);
  },
  ligne3() {
    return this.plateau.slice(6, 9);
  }
}
→ slice(0,3) → prend les éléments 0,1,2 → première ligne. → slice(3,6) → prend les éléments 3,4,5 → deuxième ligne. → slice(6,9) → prend les éléments 6,7,8 → troisième ligne.

→ Et dans le <template>, on fait 3 fois :

vue
Copier
<div class="ligne">

    {{ case }}
  </div>
</div>

→ Pour la deuxième ligne, index est 0,1,2 → mais en réalité, les cases sont 3,4,5 → donc on doit ajuster l’index.

🎯 Objectif : Implémenter data() dans <script setup>
Mais attention : dans <script setup>, on n’utilise PAS data() comme avant.
On utilise plutôt ref() ou reactive() pour créer des variables réactives (qui changent et mettent à jour l’écran automatiquement).

🧠 Pourquoi ?
Parce que dans le “setup”, on écrit du code comme si c’était un script normal — on déclare des variables avec ref(), et Vue les rend “réactives” (elles se mettent à jour quand on les change).

✅ Étape 1 : Importer ref (tu l’as déjà fait 👍)

Copier

→ ref() permet de créer une variable réactive.

Ah, très bonne observation — cette erreur vient de TypeScript et elle est très utile 😊
Elle te dit :

“Tu as utilisé case comme nom de variable dans un v-for, mais case est un mot réservé en JavaScript/TypeScript — tu ne peux pas l’utiliser comme nom de variable.”

❗ Pourquoi cette erreur ?
Dans v-for="(case, index) in ligne1", tu as écrit case → mais en JavaScript/TypeScript, case est un mot-clé utilisé dans les switch :

ts
Copier
switch (x) {
  case 1:
    console.log('un');
    break;
}
→ Donc TypeScript te dit : “Tu ne peux pas utiliser case comme nom de variable — c’est interdit !”

✅ Solution : Changer le nom de la variable
Tu peux utiliser n’importe quel autre nom, par exemple :

cell (comme “cellule”)
item
content
symbole
valeur
