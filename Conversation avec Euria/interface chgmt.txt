❌ Problème 1 : La couleur du fond ne change pas
🧠 Pourquoi ?
Parce que tu as écrit :

css
Copier
body {
  background-color: #f0f8ff;
}
→ Mais dans Vue 3, le body n’est pas toujours contrôlé par ton composant — surtout si tu utilises Vite (le kit que tu as installé).
→ Le fond est souvent géré par un fichier global, pas par App.vue.

✅ Solution : On va changer le fond dans un fichier global
1. Crée un fichier src/assets/main.css
→ Dans VS Code, va dans src/ → clique droit → New File → nomme-le :
assets/main.css

✅ C’est un fichier de style global — il s’appliquera à tout le site.

2. Colle ce code dans main.css :
css
Copier
body {
  background-color: #f0f8ff;
  font-family: Arial, sans-serif;
  padding: 20px;
  margin: 0;
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 100vh;
}
✅ background-color: #f0f8ff = fond bleu clair.
✅ display: flex; justify-content: center; align-items: center; = centre tout le contenu horizontalement et verticalement.
✅ min-height: 100vh = la page fait au moins la hauteur de l’écran.

3. Importe ce fichier dans main.js
→ Va dans src/main.js (ou src/main.ts si tu as ça).

Tu vois peut-être :

js
Copier
import { createApp } from 'vue'
import App from './App.vue'

createApp(App).mount('#app')
→ Ajoute cette ligne en haut :

js
Copier
import './assets/main.css'
→ Ton fichier devient :

js
Copier
import './assets/main.css'
import { createApp } from 'vue'
import App from './App.vue'

createApp(App).mount('#app')
✅ Tu dis à Vue : “Utilise ce fichier CSS pour tout le site.”

4. Sauvegarde et regarde ton site
→ Appuie sur Ctrl + S → ton site se rafraîchit.
→ Le fond est maintenant bleu clair, et tout le contenu est centré ! 🎉

❌ Problème 2 : Les boutons ne sont pas centrés
🧠 Pourquoi ?
Parce que tu as centré le titre et le paragraphe avec text-align: center, mais les boutons sont des éléments block — ils prennent toute la largeur, et text-align ne les centre pas.

✅ Solution : On va les centrer avec display: flex
1. Dans App.vue, va dans <template>
Tu as :

vue
Copier
<h1>Hello World !</h1>
<p>je ne comprends pas grand chose</p>
<button @click="counter++">Clique-moi ! ({{ counter }})</button>
<button @click="counter = 0">Réinitialiser</button>
→ Enveloppe les boutons dans un conteneur :

vue
Copier
<div class="buttons">
  <button @click="counter++">Clique-moi ! ({{ counter }})</button>
  <button @click="counter = 0">Réinitialiser</button>
</div>
✅ div class="buttons" = un conteneur pour les boutons.

2. Dans <style scoped>, ajoute ce code :
css
Copier
.buttons {
  display: flex;
  justify-content: center;
  gap: 10px;
  margin-top: 20px;
}
✅ display: flex = les boutons sont placés côte à côte.
✅ justify-content: center = centrés horizontalement.
✅ gap: 10px = espace entre les boutons.
✅ margin-top: 20px = espace au-dessus des boutons.

3. Sauvegarde et regarde ton site
→ Les boutons sont maintenant centrés, avec un espace entre eux. 🎉
